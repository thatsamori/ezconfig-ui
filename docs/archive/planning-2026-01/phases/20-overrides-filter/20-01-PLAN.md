**Bug Analysis:**
When "Show overrides only" is enabled but no saved weapon data exists on disk:
1. API returns `{ success: true, data: {} }` (no Weapon key)
2. `json.data?.Weapon` is undefined, so `setOverrideMap` never called
3. `overrideMap` state stays `null`
4. Filtering conditions `showOverridesOnly && overrideMap` are falsy
5. No filtering happens - all weapons/categories shown with "No overrides" messages
</context>
