<task type="auto">
  <name>Task 1: Create users service with env bootstrap</name>
  <files>src/lib/auth/types.ts, src/lib/auth/service.ts, src/lib/env.ts</files>
  <action>
1. Create src/lib/auth/types.ts with:
   - UserRole type: 'viewer' | 'preset_creator' | 'config_editor' | 'global_admin'
   - User interface: { username: string, password: string, role: UserRole }
   - AuthToken interface: { username: string, role: UserRole, token: string }

2. Create src/lib/auth/service.ts with:
   - USERS_PATH from env (default './users.json')
   - getUsers(): Promise<User[]> - reads users.json, returns empty array if not exists
   - saveUsers(users: User[]): Promise<void> - writes users.json
   - bootstrapAdmin(): Promise<void> - if users.json empty/missing AND ADMIN_USERNAME+ADMIN_PASSWORD set, create admin user with global_admin role
   - validateCredentials(username: string, password: string): Promise<User | null> - plain text comparison
   - generateToken(user: User): string - simple random token (crypto.randomUUID())

3. Update src/lib/env.ts to add:
   - usersPath: process.env.USERS_PATH || './users.json'
   - adminUsername: process.env.ADMIN_USERNAME || ''
   - adminPassword: process.env.ADMIN_PASSWORD || ''

Follow presets/service.ts pattern for file I/O (fs.readFile/writeFile with try/catch).
Do NOT use bcrypt or any hashing - plain text passwords per CONTEXT.md.
  </action>
  <verify>Create a test script that imports the service and calls bootstrapAdmin() with env vars set, then validates credentials work</verify>
  <done>Users service exports all functions, env.ts has new vars, types defined</done>
</task>

<task type="auto">
  <name>Task 2: Create auth API endpoints</name>
  <files>src/app/api/auth/login/route.ts, src/app/api/auth/logout/route.ts, src/app/api/auth/me/route.ts, src/lib/auth/tokens.ts</files>
  <action>
1. Create src/lib/auth/tokens.ts for server-side token management:
   - activeTokens: Map<string, { username: string, role: UserRole }> (in-memory store)
   - storeToken(token: string, user: User): void
   - validateToken(token: string): { username: string, role: UserRole } | null
   - removeToken(token: string): void

2. Create POST /api/auth/login endpoint:
   - Request body: { username: string, password: string }
   - Call bootstrapAdmin() first (ensures admin exists on first request)
   - Validate credentials via service
   - If valid: generate token, store in tokens map, return { success: true, token, user: { username, role } }
   - If invalid: return 401 { success: false, error: 'Invalid credentials' }

3. Create POST /api/auth/logout endpoint:
   - Request body: { token: string }
   - Remove token from map
   - Return { success: true }

4. Create GET /api/auth/me endpoint:
   - Read token from Authorization header (Bearer token)
   - Validate token
   - If valid: return { authenticated: true, user: { username, role } }
   - If invalid: return 401 { authenticated: false }

Follow existing API route patterns (NextResponse.json, try/catch error handling).
  </action>
  <verify>curl -X POST localhost:3000/api/auth/login with valid credentials returns token; GET /api/auth/me with token returns user</verify>
  <done>Login returns token and user info, logout clears token, me endpoint validates token</done>
</task>
