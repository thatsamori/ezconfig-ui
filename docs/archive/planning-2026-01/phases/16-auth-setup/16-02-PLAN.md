<task type="auto">
  <name>Task 1: Create auth store and API protection</name>
  <files>src/lib/store/authStore.ts, src/lib/store/index.ts, src/lib/auth/index.ts</files>
  <action>
1. Create src/lib/store/authStore.ts with Zustand + persist:
   - State: { token: string | null, user: { username: string, role: UserRole } | null, isAuthenticated: boolean, isLoading: boolean }
   - Actions:
     - login(username: string, password: string): Promise<boolean> - calls /api/auth/login, stores token+user, returns success
     - logout(): Promise<void> - calls /api/auth/logout, clears state
     - checkAuth(): Promise<void> - calls /api/auth/me with stored token, updates isAuthenticated
     - clearAuth(): void - clears token and user (for invalid token cleanup)
   - Persist token to localStorage key 'ezconfig-auth'
   - On hydration, set isLoading=true, call checkAuth(), then isLoading=false

2. Update src/lib/store/index.ts to export authStore

3. Create src/lib/auth/index.ts barrel export:
   - Export types from ./types
   - Export getAuthHeader helper: () => { Authorization: `Bearer ${token}` } or empty object

Do NOT persist user object - only token. User is fetched via checkAuth() on hydration.
  </action>
  <verify>Import authStore, call login with valid credentials, verify token persisted to localStorage</verify>
  <done>Auth store with login/logout/checkAuth actions, token persistence, barrel exports</done>
</task>

<task type="auto">
  <name>Task 2: Create login UI and app gate</name>
  <files>src/components/auth/LoginForm.tsx, src/components/auth/AuthGate.tsx, src/components/auth/index.ts, src/app/page.tsx</files>
  <action>
1. Create src/components/auth/LoginForm.tsx:
   - Form with username input, password input, submit button
   - Use existing UI components (Input, Button, Card)
   - On submit: call authStore.login(), show error toast on failure (use sonner)
   - Disable form while loading
   - Simple centered card layout

2. Create src/components/auth/AuthGate.tsx:
   - Props: { children: React.ReactNode }
   - Uses authStore to check isAuthenticated, isLoading
   - If isLoading: show simple "Loading..." centered text
   - If not authenticated: render LoginForm
   - If authenticated: render children

3. Create src/components/auth/index.ts barrel export

4. Update src/app/page.tsx:
   - Wrap entire content in AuthGate
   - Add logout button to header (shows username, click to logout)
   - Only show main content when authenticated

Keep login form minimal - username, password, submit. No password reset, no remember me.
Use existing Shadcn components for consistent styling.
  </action>
  <verify>npm run dev, visit localhost:3000, see login form, enter valid credentials, see main app</verify>
  <done>Login form renders when not authenticated, main app renders when authenticated, logout works</done>
</task>
