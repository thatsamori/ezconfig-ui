<objective>
Remove deprecated store method usage from preset components and simplify preset loading flow.

The v2.0 state model removed working/saved distinction - all changes are immediately persisted.
Preset components still use deprecated methods that need to be updated:
- `hasUnsavedChanges` (always false - no working state)
- `savedValues` (aliased to `values`)
- `resetWorkingValues` (no-op)

The "Unsaved Changes" blocking dialog is no longer needed since there are no unsaved changes.
</objective>
