<task type="auto">
  <name>Task 2: Create SelectiveApplyDialog component</name>
  <files>src/components/SelectiveApplyDialog.tsx</files>
  <action>
Create a dialog for selective apply with the following features:

**Props:**
- open: boolean
- onOpenChange: (open: boolean) => void
- onApplyComplete: () => void (called after successful apply)

**State:**
- commands: string[] (fetched on open)
- selectedCommands: Set<string> (all selected by default)
- searchQuery: string
- password: string
- isLoading: boolean (for fetching)
- isApplying: boolean

**Layout (from top to bottom):**
1. DialogHeader with title "Apply to Game" and description
2. Search input with placeholder "Search commands..."
3. Select All / Deselect All buttons row
4. Scrollable command list (max-h-[300px] overflow-y-auto)
   - Each row: Checkbox + command text (truncated if too long)
   - Commands sorted alphabetically
   - Filtered by search query (case-insensitive substring match)
5. Password input with label "EZCONFIG_PASSWORD"
6. DialogFooter with Cancel and Apply buttons

**Behavior:**
- On open: fetch /api/apply/preview, populate commands, select all
- Search filters the visible list but preserves selection state
- Apply button:
  1. Validate password not empty
  2. POST to /api/apply with { password, commands: [...selectedCommands] }
  3. Show toast on success/failure
  4. Close dialog on success, call onApplyComplete

**API change needed:** The /api/apply endpoint needs to accept optional `commands` array. If provided, use those instead of calling buildRconCommands().

Display format for commands: Show the full command string. Users can use search to find specific commands.

Use existing component patterns:
- Dialog, DialogContent, DialogHeader, DialogTitle, DialogDescription, DialogFooter from @/components/ui/dialog
- Checkbox from @/components/ui/checkbox
- Input from @/components/ui/input
- Button from @/components/ui/button
- Label from @/components/ui/label
