   - Handle loading and empty states
   - Display grid of Card components (2-3 columns responsive)

   - Use hasUnsavedChanges from configStore to control load behavior

2. Load flow with AlertDialog:
   - If hasUnsavedChanges is true when user clicks Load:
     - Show AlertDialog: "You have unsaved changes. Save or discard them before loading a preset."

   - If hasUnsavedChanges is false:

3. On confirmed load:
   - Fetch GET /api/presets/[name] to get preset data
   - Call loadPreset(data) from configStore
   - Show toast success: "Loaded preset: {title}"

4. Create src/components/presets/index.ts barrel export
