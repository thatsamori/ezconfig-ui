<task type="auto">
  <name>Task 2: Add POST /api/config/bulk-weapons endpoint</name>
  <files>src/app/api/config/bulk-weapons/route.ts</files>
  <action>
Create new API endpoint that applies a config entry to all weapons for a given category.

Request body:
```json
{
  "category": "General" | "Strike" | "AltStrike" | "Stab" | "AltStab",
  "entry": { "ConfigKey": value }
}
```

Implementation:
1. Parse request body, validate category and entry structure
2. Use scanDatabaseStructure() to get all weapons from Weapon group
3. Validate the entry against schema for the category using validateEntries()
4. For each weapon:
   a. Read existing entries with readCategory(weapon, category)
   b. Merge or add the new entry (replace if key exists, append if not)
   c. Write back with writeCategory(weapon, category, entries)
5. Return success response with count of weapons updated

Response:
```json
{ "success": true, "data": { "weaponsUpdated": 15 } }
```

Error cases:
- Invalid category: 400 with error message
- Invalid entry (schema validation): 400 with validation errors
- File system error: 500 with error message

Security: Validate category is one of the known attack types or "General". Do NOT allow arbitrary paths.
  </action>

- npm run build passes
  </verify>
  <done>API endpoint accepts category + entry, validates against schema, writes to all weapon files, returns count</done>
