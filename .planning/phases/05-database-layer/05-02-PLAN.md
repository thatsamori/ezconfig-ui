<task type="auto">
  <name>Task 1: Create databases structure endpoint</name>
  <files>src/app/api/databases/route.ts, src/lib/database/structure.ts</files>
  <action>
Create endpoint to return database structure for UI navigation.

**Structure service** (`src/lib/database/structure.ts`):

1. **`scanDatabaseStructure(): Promise<DatabaseStructure>`**
   - Scan `DATABASES_PATH` directory recursively
   - Build structure: `{ [database: string]: string[] | { [subDatabase: string]: string[] } }`
   - For flat databases (e.g., `Character/`): Return `{ "Character": ["General", "Movement", "Combat"] }`
   - For grouped databases (e.g., `Weapon/`): Return `{ "Weapon": { "Greatsword": ["General", "Strike", ...], ... } }`
   - A folder is a "group" if it contains only subfolders (no JSON files directly)
   - A folder is a "database" if it contains JSON files
   - Category names are JSON filenames without extension

**API Route** (`src/app/api/databases/route.ts`):

GET handler:
1. Call `scanDatabaseStructure()`
2. Return `{ success: true, data: structure }`
3. On error: Return 500 with error message

Note: This endpoint scans the filesystem each time. For v1.0 this is acceptable since the structure doesn't change frequently. Caching can be added in Polish phase if needed.

<task type="auto">
  <name>Task 2: Create apply endpoint with RCON integration</name>
  <files>src/app/api/apply/route.ts, src/lib/database/apply.ts</files>
  <action>
Create endpoint to apply saved config to game via RCON.

**Apply service** (`src/lib/database/apply.ts`):

1. **`buildRconCommands(): Promise<string[]>`**
   - Scan all category files in DATABASES_PATH
   - For each non-empty category file:
     - Read entries
     - Convert each value to RCON format using `formatValue()` from `@/lib/rcon/formatters`
     - Build command: `string ezconfig {database} {category} {JSON.stringify(convertedEntries)}`
   - Return array of commands (WipeDatabases is prepended by caller)

2. **`applyConfig(): Promise<{ success: boolean; commandsSent: number; error?: string; failedAt?: string }>`**
   - Build command array: `["string ezconfig WipeDatabases", ...buildRconCommands()]`
   - Execute via `executeBatchCommands()` from `@/lib/rcon/service`
   - Return success with commandsSent count
   - On RCON error: Return failure with error message and failedAt database/category

**Value conversion for RCON:**
- Each entry `{ "Key": nativeValue }` becomes `{ "Key": "RCONFormattedValue" }`
- Get dataType from schema using `getSchemaForCategory()`
- Use `formatValue(dataType, value)` for conversion

**API Route** (`src/app/api/apply/route.ts`):

POST handler:
1. Parse request body: `{ password: string }`
2. Validate password against `process.env.EZCONFIG_PASSWORD`
3. If invalid: Return 401 `{ success: false, error: "Unauthorized" }`
4. Call `applyConfig()`
5. Return result

Update `src/lib/env.ts` to include `ezconfigPassword: process.env.EZCONFIG_PASSWORD || ''`.
