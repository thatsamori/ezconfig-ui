<task type="auto">
  <name>Fix UAT-002: Weapons override filter not showing configured values</name>
  <files>src/components/weapons/WeaponConfigTab.tsx</files>
  <action>
The override filter fetches from `/api/databases/overrides` which reads persisted files. But with the new state model, values write to API async - there may be timing issues or the override map may not reflect current store state.

Investigation needed:
1. Check if `/api/databases/overrides` returns correct data when values exist
2. The issue might be that overrideMap is being compared against a stale empty object

Likely fix:
The current logic fetches overrideMap only once when toggle becomes true. But the data might not have been persisted yet, or the API might not be returning the right structure.

Option A: Use store state directly
- Instead of fetching from API, derive override presence from configStore.values
- Add a selector/helper to check which weapons have values

Option B: Force refetch on toggle
- Clear overrideMap when toggle changes
- Refetch fresh data each time toggle is enabled

Implement Option A (preferred - more reliable with new state model):
1. Import useConfigStore and access values
2. Compute overrideMap locally from `values.weapons`:
   ```typescript
   const storeValues = useConfigStore((state) => state.values);
   const overrideMapFromStore = useMemo(() => {
     const map: GroupedOverrideMap = {};
     for (const [weapon, categories] of Object.entries(storeValues.weapons)) {
       map[weapon] = {};
       for (const category of Object.keys(categories)) {
         map[weapon][category] = Object.keys(categories[category]).length > 0;
       }
     }
     return map;
   }, [storeValues.weapons]);
   ```
3. Use this computed map instead of fetching from API
4. Remove the useEffect that fetches from `/api/databases/overrides`
  </action>

1. Configure some weapon values (e.g., set a value on Greatsword)
2. Go to Weapons tab
3. Toggle "Show overrides only" ON
4. Verify configured weapon appears in the filtered list
  </verify>
  <done>Show overrides only filter correctly shows weapons with configured values from store</done>
</task>
