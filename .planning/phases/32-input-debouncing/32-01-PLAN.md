Output: FloatInput uses local state during editing, only calls onChange on blur

**Current behavior:**
FloatInput calls `onChange` on every keystroke via `handleChange`. Since v2.0 uses immediate persistence, this triggers a DB write for each character typed.

**Desired behavior:**
- User types in input field → local state updates instantly
- User clicks away (blur) → DB write happens once
- User presses Enter → same as blur (commits value)

**Pattern:** Use local state for intermediate values, sync on blur.
</context>

<task type="auto">
  <name>Task 1: Update FloatInput to use local state and commit on blur</name>
  <files>src/components/config/FloatInput.tsx</files>
  <action>
Modify FloatInput to maintain local state during editing:

1. Add useState for local input value (as string to handle intermediate states like "1.")
2. Initialize local state from prop value on mount and when prop changes externally
3. Update local state on every keystroke (no onChange call yet)
4. On blur: parse the local value, if valid number call onChange
5. On Enter key: same as blur - commit the value
6. Handle edge cases:
   - If user clears input entirely, keep last valid value on blur
   - If user types invalid number (e.g. "abc"), keep last valid value
   - Allow intermediate states like "1." or "-" while typing

Implementation:
```tsx
const [localValue, setLocalValue] = useState(String(value));

// Sync when external value changes (e.g., from reset)
useEffect(() => {
  setLocalValue(String(value));
}, [value]);

const handleChange = (e) => {
  setLocalValue(e.target.value); // No onChange call
};

const handleBlur = () => {
  const parsed = parseFloat(localValue);
  if (!isNaN(parsed)) {
    onChange(parsed);
  } else {
    setLocalValue(String(value)); // Revert to last valid
  }
};

const handleKeyDown = (e) => {
  if (e.key === 'Enter') {
    e.currentTarget.blur(); // Triggers handleBlur
  }
};
```

Update Input component to use localValue as value, add onBlur and onKeyDown handlers.
