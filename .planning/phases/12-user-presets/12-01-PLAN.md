<task type="auto">
  <name>Task 1: Extend preset service for user presets</name>
  <files>src/lib/presets/service.ts</files>
  <action>
Add user preset functionality to the existing service:

1. Add `getUserPresetsPath()` - returns `join(getPresetsRoot(), 'User')`
2. Add `listUserPresets()` - same logic as listStaticPresets but for User directory
3. Add `saveUserPreset(name: string, manifest: PresetManifest, data: PresetData)`:
   - Validate preset name (no path traversal, alphanumeric + hyphens + underscores only)
   - Create directory at User/{name}/
   - Write manifest.json
   - Write Character/{category}.json files for each category in data.character
   - Write Weapon/{weaponName}/{category}.json files for each weapon/category in data.weapons
   - ConfigEntry format: array of single-key objects like `[{ "key": value }, ...]`
4. Add `deleteUserPreset(name: string)`:
   - Validate name
   - Recursively delete User/{name}/ directory
   - Return success/failure

Validation for preset name: `/^[a-zA-Z0-9_-]+$/` - reject names with spaces, dots, slashes, etc.
  </action>
  <verify>TypeScript compiles without errors</verify>
  <done>
    - getUserPresetsPath returns correct path
    - listUserPresets returns user presets
    - saveUserPreset creates preset directory with correct structure
    - deleteUserPreset removes preset directory
  </done>
</task>

<task type="auto">
  <name>Task 2: Create user preset API endpoints</name>
  <files>src/app/api/presets/user/route.ts, src/app/api/presets/user/[name]/route.ts</files>
  <action>
Create API endpoints for user preset management:

1. POST /api/presets/user (src/app/api/presets/user/route.ts):
   - Accept body: `{ name: string, title: string, description: string, data: PresetData }`
   - Call saveUserPreset with name, manifest {title, description}, data
   - Return 200 with `{ success: true }` or 400/500 with error

2. GET /api/presets/user (same file):
   - Call listUserPresets
   - Return `{ success: true, data: PresetInfo[] }`

3. DELETE /api/presets/user/[name] (src/app/api/presets/user/[name]/route.ts):
   - Validate name parameter
   - Call deleteUserPreset
   - Return 200 with `{ success: true }` or 400/404/500 with error

4. Update GET /api/presets (existing route.ts):
   - Also fetch user presets with listUserPresets
   - Return both in response: `{ success: true, data: { static: PresetInfo[], user: PresetInfo[] } }`
  </action>
  <verify>npm run build succeeds</verify>
  <done>
    - POST /api/presets/user creates new user preset
    - GET /api/presets/user lists user presets only
    - DELETE /api/presets/user/[name] removes preset
    - GET /api/presets returns both static and user presets
  </done>
</task>
