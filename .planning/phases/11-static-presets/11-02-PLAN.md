<task type="auto">
  <name>Task 2: Implement load preset flow with safety checks</name>
  <files>src/components/presets/PresetGallery.tsx, src/lib/store/configStore.ts</files>
  <action>
Implement the load flow with safety checks per CONTEXT.md:

1. Add store action to configStore.ts:
   - loadPresetData(data: PresetData): void
   - Clears existing savedValues and workingValues
   - Sets savedValues from preset data
   - Resets workingValues to empty
   - Sets hasUnsavedChanges to false
   - Clears loadedCategories Set

2. In PresetGallery.tsx, implement load flow:
   - State: selectedPreset (null | string), isLoadDialogOpen
   - When card's onLoad clicked:
     a. If hasUnsavedChanges: show blocking alert "You have unsaved changes. Save or reset your changes before loading a preset."
     b. If clean: show confirmation dialog "Load preset '{title}'? This will replace your current configuration."
   - On confirm:
     a. Fetch /api/presets/{name}
     b. Call store.loadPresetData(response.data)
     c. Close dialog
     d. Show brief success state (optional: toast or inline message)

3. Use AlertDialog from Shadcn for both dialogs:
   - Blocking dialog: single "OK" button, no action
   - Confirmation dialog: "Cancel" and "Load Preset" buttons

Error handling: If load fails, show error in dialog (don't close).
  </action>
  <verify>Manual test: try loading preset with/without unsaved changes, verify correct dialog appears</verify>
  <done>
    - loadPresetData store action works correctly
    - Blocking dialog shown when unsaved changes exist
    - Confirmation dialog shown when clean
    - Preset loads into working state successfully
  </done>
</task>
