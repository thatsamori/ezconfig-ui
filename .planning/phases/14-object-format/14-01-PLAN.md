<objective>
Convert JSON storage from array format `[{key: value}, {key2: value2}]` to single object format `{key: value, key2: value2}`.

Purpose: Simplify data structure - each config file becomes a single object instead of an array of single-key objects.
Output: All database layer code updated to use object format, API contracts updated.
</objective>
