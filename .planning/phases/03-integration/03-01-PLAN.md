<task type="auto">
  <name>Task 1: Create Game.ini parser utility</name>
  <files>src/lib/gameini/parser.ts, src/lib/gameini/index.ts</files>
  <action>
Create a utility to parse Game.ini sections:

1. Read file from path specified by env.gameIniPath
2. Parse INI format:
   - Lines starting with `[EZCONFIG_` are section headers
   - Extract category and group from section name (e.g., `EZCONFIG_Character_Movement` → Character, Movement)
   - For weapons: `EZCONFIG_{WeaponName}_{GroupName}` → weapon name, group name
   - Parse key=value pairs within each section
3. Convert values based on expected data types from schemas:
   - Look up configKey in characterConfigFlatMap or weaponConfigFlatMap
   - Convert string values: "True"/"False" → boolean, numeric strings → number
   - Vector format `X=1.00,Y=2.00,Z=3.00` → {x: 1, y: 2, z: 3}
   - Vector2D format `X=1.00,Y=2.00` → {x: 1, y: 2}
   - FloatArray format `(1.00,2.00,3.00)` → [1, 2, 3]
4. Return structured data matching store's initializeFromGameIni signature:
   - characterValues: Record<string, any>
   - weaponValues: Record<string, Record<string, any>>

Handle edge cases:
- File not found: return empty objects (fresh game state)
- Malformed lines: skip with console.warn
- Unknown config keys: skip (not in our schema)
  </action>
  <verify>Create test file with sample Game.ini content and verify parsing works correctly</verify>
  <done>Parser correctly extracts character and weapon values from Game.ini format, converts types, handles missing file gracefully</done>
</task>
