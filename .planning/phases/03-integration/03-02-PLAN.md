**RCON command format (from INTEGRATIONS.md):**
- Character: `string ezconfig Character {GroupName} {ConfigKey} {FormattedValue}`
- Weapon: `string ezconfig {WeaponName} {GroupName} {ConfigKey} {FormattedValue}`

**Value formatting:**
- Boolean: `"True"` or `"False"`
- Float: `"0.00"` (2 decimal places)
- Vector: `"X=0.00,Y=0.00,Z=0.00"`
- Vector2D: `"X=0.00,Y=0.00"`
- FloatArray: `"(0.00,0.00,0.00)"`

**Constraining decisions:**
- PROJECT.md: Sequential RCON commands (not parallel)
- 01-02: getStagedChanges() collects only staged values
- INTEGRATIONS.md: Use env vars for RCON credentials (not hardcoded)

<task type="auto">
  <name>Task 1: Create RCON service with server action</name>
  <files>src/lib/rcon/service.ts, src/lib/rcon/formatters.ts, src/lib/rcon/index.ts, src/app/actions/rcon.ts</files>
  <action>
1. Create formatters.ts with value formatting functions (extract from rconExamples.ts):
   - formatBoolean(value: boolean): string → "True" or "False"
   - formatFloat(value: number): string → value.toFixed(2)
   - formatVector(value: {x,y,z}): string → "X=0.00,Y=0.00,Z=0.00"
   - formatVector2D(value: {x,y}): string → "X=0.00,Y=0.00"
   - formatFloatArray(value: number[]): string → "(0.00,0.00,0.00)"
   - formatValue(dataType: DataType, value: any): string → dispatch to correct formatter

2. Create service.ts with RCON connection logic:
   - Import Rcon from 'rcon-client'
   - Create async function sendConfigUpdate that:
     a. Connects using env.rcon credentials (host, port, password)
     b. Sends command string
     c. Closes connection (or reuse for batch)
     d. Returns response or throws on error
   - For batch operations, keep connection open during batch

3. Create server action applyConfigChanges in src/app/actions/rcon.ts:
   - Mark with "use server"
   - Accept staged changes: { character: Record<string, any>, weapons: Record<string, Record<string, any>> }
   - Validate env (RCON_HOST, RCON_PORT, RCON_PASSWORD required)
   - Build RCON commands for each staged value:
     a. Look up config entry from flat maps to get dataType
     b. Look up group name for config key
     c. Format value using formatValue
     d. Build command string
   - Execute commands SEQUENTIALLY (for...of loop with await)
   - Return success/error status and count of commands executed

Important: rcon-client may have issues with rapid sequential connections. Consider:
- Single connection for entire batch
- Small delay between commands if needed (100ms)
  </action>
  <verify>

3. Call applyConfigChanges and verify RCON command is sent
4. Check game server received the command (if accessible)
  </verify>
  <done>RCON service sends formatted commands to game server, handles connection lifecycle, executes sequentially</done>
</task>
