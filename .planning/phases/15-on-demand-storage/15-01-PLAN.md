1. Modify `writeCategory` function:
   - If `data` is empty object (Object.keys(data).length === 0):
     - Try to delete the file at `filePath` using `unlink()`
     - Ignore ENOENT errors (file already doesn't exist)
     - After successful delete, call new `cleanupEmptyDirectories(dir)` helper
   - Else (data has keys):
     - Keep existing behavior: create dirs, write file

2. Add `cleanupEmptyDirectories(dirPath: string)` helper function:
   - Read directory contents
   - If directory is empty, delete it with `rmdir()`
   - Recurse up to parent directory (but stop at getDatabasesRoot())
   - Ignore errors (directory not empty, doesn't exist, etc.)

3. Import `unlink` and `rmdir` from 'fs/promises' at top of file

IMPORTANT: Do NOT delete the Databases root directory itself, only subdirectories.
