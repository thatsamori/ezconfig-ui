<task type="auto">
  <name>Task 1: Create ActionButtons component with Save/Reset/Apply</name>
  <files>src/components/ActionButtons.tsx</files>
  <action>
Create a new ActionButtons component that replaces ApplyChangesButton:

**Three buttons:**
1. **Save Changes** - Enabled when hasUnsavedChanges is true
   - Iterates over workingValues (character and weapons)
   - For each category with changes, POST to /api/config/{database}/{category}
   - On success: copy working values to saved values, clear working values
   - Show toast with count of categories saved

2. **Reset Working Changes** - Enabled when hasUnsavedChanges is true
   - Shows confirmation dialog (use AlertDialog from shadcn)
   - On confirm: call resetWorkingValues() from store
   - Show toast "Working changes discarded"

3. **Apply to Game** - Enabled when hasUnsavedChanges is FALSE (only apply saved config)
   - POST to /api/apply with password from prompt
   - Use window.prompt() for password input (simple, no need for fancy dialog)
   - On success: show toast with commandsSent count
   - On error: show toast with error message

**Layout:** Flex row with gap, Save on left, Reset in middle, Apply on right. Use destructive variant for Reset.

**Store integration:**
- Use hasUnsavedChanges to control button enabled states
- After Save: need to update savedValues with working values and clear working values
- Add new store action: commitWorkingToSaved() that does this atomically

**Why commitWorkingToSaved instead of multiple setSavedValue calls:**
Batch updating prevents intermediate hasUnsavedChanges calculations and potential race conditions.

<task type="auto">
  <name>Task 2: Add commitWorkingToSaved action to store</name>
  <files>src/lib/store/configStore.ts</files>
  <action>
Add a new action to ConfigState interface and implementation:

```typescript
commitWorkingToSaved: () => void;
```

Implementation:
1. Deep merge workingValues into savedValues (don't overwrite, merge)
2. Clear workingValues (set back to empty objects)
3. Set hasUnsavedChanges to false

The merge logic:
- For character: savedValues.character[category][key] = workingValues.character[category][key]
- For weapons: savedValues.weapons[weapon][category][key] = workingValues.weapons[weapon][category][key]
- Then clear workingValues.character and workingValues.weapons

This is called AFTER successful API save to update local state.
  </action>
